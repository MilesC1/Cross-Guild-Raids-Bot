# Optional evidence to add later

A portfolio repository is stronger when screenshots show the software doing
something, but production privacy matters more than visual completeness.

Safe additions:

1. A synthetic walkthrough on two temporary Discord test servers showing one
   source message and its mirrored destination.
2. A short GIF of a synthetic source edit updating its test-server copy.
3. A screenshot of the bot's public-facing raid/lobby UX with fabricated users.
4. An aggregate, non-identifying throughput chart if you later instrument daily
   counts. Label measured counts separately from estimated fan-out.

Avoid screenshots or exports containing real usernames, message text, guild or
channel IDs, user IDs, moderator actions, raw logs, webhook URLs, hostnames,
authentication material, or private community discussions.
