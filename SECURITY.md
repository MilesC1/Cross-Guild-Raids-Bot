# Security and privacy

This public repository is intentionally disconnected from the production bot.
It contains no live token, webhook URL, real database, production endpoint,
operational log, user record, or real Discord server/channel/message identifier.

The runnable example generates synthetic identifiers and holds simulated
message content only in memory.

Please do not submit real production credentials or user information in an
issue. If this repository is later connected to GitHub's private vulnerability
reporting, security-sensitive reports should use that channel.
